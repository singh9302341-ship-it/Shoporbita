SHOPORBIT — STARTER WEBSITE
============================

WHAT'S INCLUDED
- index.html: responsive affiliate product-discovery website
- README.txt: setup and editing instructions

IMPORTANT BEFORE PUBLISHING
1. This is a static affiliate recommendation site, not a checkout/store.
2. The six product cards are DEMO content. Their prices and descriptions are illustrative.
3. No real affiliate links are included. Add your own approved tracking URLs.
4. Do not copy retailer product photos, descriptions, prices, or logos unless the relevant platform's terms permit it.
5. Keep affiliate disclosures clear and close to affiliate links.
6. If approved for Amazon Associates, display exactly:
   "As an Amazon Associate I earn from qualifying purchases."
   Also use a clear link-level disclosure as Amazon requires.
7. Keep retailer prices current. Better yet, avoid displaying a price unless you can maintain it accurately.

HOW TO EDIT PRODUCTS
Open index.html in a text editor.
Find: const products = [
Each product is one object, for example:
{name:"Wireless headphones",cat:"Electronics",price:1499,platform:"Amazon",
 icon:"🎧",desc:"Your short description.",url:"PASTE_YOUR_TRACKING_LINK_HERE"},

Allowed categories in the starter: Electronics, Fashion, Home, Beauty, Travel.
Platform is a display label only. The URL must be your own valid affiliate tracking link from the programme/network dashboard.
To add a product, copy one object line and change its values. Keep commas and quotation marks.

HOW TO PREVIEW
- On a computer: double-click index.html to open it in a browser.
- On Android: extract the ZIP and open index.html with a browser or HTML viewer.

FREE DEPLOYMENT (RECOMMENDED: NETLIFY DROP)
1. Extract the ZIP so you have a folder containing index.html.
2. Create/sign in to a Netlify account.
3. Open https://app.netlify.com/drop
4. Drag the extracted folder into the upload area (or use the file picker).
5. Netlify publishes a preview URL ending in netlify.app.
6. Test every page/link on mobile. Rename the site in Netlify site settings if the name is available.
7. Free plan quotas and terms can change; check Netlify's current plan details.

Alternative: Cloudflare Pages can host static files. Follow its current Direct Upload or Git integration guide.
Do not use GitHub Pages for a commercial affiliate website: GitHub's official Pages policy says it is not intended for online businesses/e-commerce sites.

Do not assume an ordinary product URL is an affiliate link.
